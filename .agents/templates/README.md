# Шаблоны Studio

Шаблон помогает агенту заполнить документ результатами работы. Он не должен попадать к пользователю как анкета с незавершёнными вопросами. Метод и ответственность заданы в ролях, общий порядок — в `.agents/workflows/pre-development.md`, правила самостоятельного исследования — в `.agents/contracts/research-ownership.md`.

| Раздел     | Шаблоны                                                                           |
| ---------- | --------------------------------------------------------------------------------- |
| Бриф       | `brief.md`: исходные сведения бизнеса                                             |
| Продукты   | `product.md`, `product-audience.md`, `product-economics.md`, `sales-process.yaml` |
| Конкуренты | `product-research-competitors.md`                                                 |
| Семантика  | `product-semantics.md`: запросы, измерения, группы и страницы                     |
| Стратегия  | `strategy.md`: аудитории, приоритеты и развитие                                   |
| Бренд      | `brand.md`: смысл, восприятие и язык                                              |
| Дизайн     | `design.md`, `asset-index.yaml`: визуальные правила и ресурсы                     |
| Материалы  | `website.md`, `presentation.md`, `creative.md`, `article-package.md`              |

Рекомендуемый размер основного документа — 600–1 000 слов. Полезное объяснение или подробное исследование может быть длиннее. Названия и порядок H2 фиксированы шаблоном и одинаковы для всех продуктов. Агент заполняет разделы результатами исследования. Частные темы раскрываются внутри H3. Если раздел неприменим, кратко объяснить причину. Структуру меняют одновременно в шаблоне, документах и инструкциях веб-ассистента.

Продукт хранит состав, применение и краткие условия; экономика — подробный расчёт и выполнение обязательств; аудитория и конкуренты — результаты исследования; продажи — путь клиента; семантика — поисковые группы и назначения страниц. Бренд и дизайн относятся ко всему проекту. Материалы применяют эти сведения к конкретной странице, слайдам, рекламе или статье.

Технический контракт — `.agents/references/studio-artifacts.md`. Документы содержат текущие сведения; история остаётся в Git. Проверка документа выполняется по запросу и не изменяет выбранный раздел.
