## Existing evidence and assets

- Existing logo, colors, typefaces, icons, imagery, layouts, guidelines, client
  materials, listings, photographs, testimonials, rights, mandatory-use status,
  and limitations; record an explicit “none” when no project assets exist

  references; source links or files and the specific observable qualities to
  pursue or avoid; record an explicit “none” when no references are supplied
- References express preference and do not grant copying or reuse rights

## Visual reference intake

- This is client taste input, not a Design decision. Store the actual files,
  provenance, rights, and usage limits in Assets; Brief records only the five
  required categories and their intake status.
- Use only `missing`, `supplied-unreviewed`, or `ready`. Design generation may
  begin only when every row is `ready`. Incomplete rows do not block Business,
  Strategy, or Brand.

| Category                         | Required client reference set                                         | Reference asset IDs | Operator likes/dislikes                             | Status |
| -------------------------------- | --------------------------------------------------------------------- | ------------------- | --------------------------------------------------- | ------ |
| Interface and website appearance | Interfaces or website screens with visible layout and UI details      |                     | Exact observable qualities, without agent inference |        |
| Typography                       | Type specimens or layouts showing the desired character and hierarchy |                     | Exact observable qualities, without agent inference |        |
| Photography                      | Actual photographs showing subject, light, composition, and grading   |                     | Exact observable qualities, without agent inference |        |
| Illustration                     | Illustration examples showing the desired visual language             |                     | Exact observable qualities, without agent inference |        |
| Marketing creative               | Banners or posts with visible text, composition, and hierarchy        |                     | Exact observable qualities, without agent inference |        |

- A mixed or unlabeled collection remains `unclassified` only while the client
  decides how to correct it and cannot satisfy any row. Do not infer a style or
  assign mixed files to a category on the client's behalf. If the client rejects
  or replaces it, remove its exact file, Assets row, and stale current links
  after verifying that no current decision still references it.
