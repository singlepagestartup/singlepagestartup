# profiles-to-knowledge-module-sources

Links a Social profile to a Knowledge Source. RBAC uses these links to determine the permitted Source IDs for retrieval and editing. A unique profile/Source pair prevents duplicate access links. Removing this relation preserves Source and its Files.

Link an employee’s source to their profile with the `default` variant. The same profile can use this knowledge across its products. Customer memory keeps its customer, store and project scope. Previously scoped sources retain their access limits when their metadata is edited. Previously paid orders keep the specification snapshots already delivered to their buyers.
