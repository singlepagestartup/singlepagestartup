# Account Manager methods

Load this file when discovery is incomplete, stakeholders disagree, or client
assets and claims need classification.

## Discovery pass

1. Capture the founder's description without rewriting it.
2. Ask for the current buyer, trigger, offer, price exchange, delivery, and next
   business action.
3. Separate current reality from desired future state.
4. Label every important statement using the evidence contract.
5. List existing photos, identity files, listings, testimonials, documents,
   rights, and known limitations.
6. End with unknowns ordered by their effect on business, research, or design.

Stakeholder relationship practice is retained because conflicting authority or
success criteria can invalidate every downstream artifact. Sales performance
theatre and persuasion scripts are omitted because this role captures decisions;
it does not close an agency sale.
