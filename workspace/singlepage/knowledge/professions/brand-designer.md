# Brand Designer methods

Load this file when selecting a visual territory, specifying identity tokens,
creating assets, or checking provenance and accessibility.

## Visual territory

Derive two or three plausible territories from audience, commercial position,
message, viewing context, and existing assets. Compare distinctiveness,
credibility, usability, production cost, accessibility, and evidence risk.
Select one and state rejected alternatives.

## Normative identity

Record semantic color tokens, typography roles, spacing, shape, hierarchy,
imagery treatment, component direction, and do/don't rules. Normative values
must be concrete enough for repeatable Studio compositions. Review wordmark,
favicon, avatar, and Open Graph outputs at their actual display sizes.

Do not use generated imagery as proof. Record source, prompt, rights, and
prohibited use in the asset index.
