## Summary

AI Chat previews are local React components in Studio, split by module, model and relation, with model-local state and small identity/navigation props. Storybook builds independently of production code. Knowledge uses Source as the editable material shared by profiles and chat tools, preserving user notes when attachments change. MCP deployment generates project client configs on Bun.

## Notes

This PR contains the complete `codex/ai-chat-ui-review` branch, including the preceding Studio and Host fixes. Separate uncommitted business-document edits and local uploaded training files are excluded.

AI Chat and the Host inspector use local Studio state. Production transfer, durable storage, authentication mutations and payment execution remain separate implementation steps. The existing production social chat retains the implemented Knowledge API. Content generation writes Studio derivatives only. The active page stores records in model-local Thread, Source and File providers. Profile stores identity and navigation only. Aggregate adapters remain in standalone examples/tests; the active page does not use them. Independent persistence, API calls and agent/tool routing remain later work. The Products document is a visual grouping, separate from Source/File/relation records; there is no documentId field in Source. Local Source fixtures demonstrate existing analyzed content; Studio performs no file analysis or indexing.

Knowledge model/relations and SDK contracts change. The repository includes generated schema changes; there is no data transfer, backfill or compatibility implementation. No deployed Knowledge dataset is being migrated. Analysis requires Poppler, FFmpeg and configured model/transcription providers.

The Host build exhausted the default Node heap; the successful build used an 8 GiB heap. The local plan and progress files are `thoughts/shared/plans/singlepagestartup/2026-10-09-studio-isolation.md` and `thoughts/shared/handoffs/singlepagestartup/studio-isolation-2026-10-09.md`.
