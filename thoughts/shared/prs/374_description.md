## Summary

Bring the Studio AI Chat model composition into the production Host: authenticated project selection and creation, document workspaces, account settings, attachments and confirmed Knowledge edits. The final review also fixes stale caches, authorization-option loss and document-confirmation races. Automatic query dependencies now connect service writes to targeted cross-client refresh without a manually maintained model graph.

The project chooser preserves the original photographic creation form. Telegram bot conversations remain under Agent and `apps/telegram`; only the unused Telegram business module is removed.
