# Research: Какие операции с заказами зависят от аккаунта

**Date**: 2026-11-16

**Researcher**: flakecode

## Research Question

Где система записывает владельца заказа, как выбирает корзину и историю покупок и какие данные позволяют установить профиль покупателя у прежних заказов?

## Summary

Корзина, прямая покупка и начальная бесплатная подписка (Initial Free) сохраняют одну и ту же пару: ID аккаунта и ID заказа. По ней API выбирает корзину и покупки, а фоновый обработчик находит получателя роли, пополнения и уведомления. ID профиля в этой паре нет. Даже если личный профиль аккаунта известен сегодня, старая связь не доказывает, от имени какого профиля сделана покупка.

### Интерфейс и кэш

Корзина в панели навигации получает текущий аккаунт из сессии. Раздел «Покупки» использует тот же аккаунт для чтения истории. В React Query ключ списка состоит из маршрута с ID аккаунта, параметров и адреса сервера. При одинаковых параметрах два профиля одного аккаунта используют один ключ. Для корзины клиент также подписывается на изменения старой связи аккаунт–заказ. Административная форма показывает эту связь у аккаунта. [Корзина](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/frontend/component/src/lib/singlepage/me/ecommerce-module/cart-default/client.tsx#L10) · [История покупок](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/frontend/component/src/lib/singlepage/me/ecommerce-module/order/list/ai-chat/ClientComponent.tsx#L11) · [Ключ и события](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/sdk/client/src/lib/singlepage/ecommerce-module/order/list.ts#L28) · [HTTP-запрос](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/sdk/server/src/lib/singlepage/ecommerce-module/order/list.ts#L53) · [Админформа](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/frontend/component/src/lib/singlepage/admin-v2/form/ClientComponent.tsx#L67).

### Что известно о старых заказах

В стандартной таблице заказов нет колонки профиля. Таблица связей содержит два обязательных внешних ключа: аккаунт и заказ. В её объявлении нет ограничения, которое оставляло бы заказу только одного владельца. Это свойство схемы, а не свидетельство наличия таких строк в рабочей базе. Связь Social между профилем и **товаром** не указывает на конкретную покупку. [Поля заказа](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/ecommerce/models/order/backend/repository/database/src/lib/fields/singlepage.ts#L3) · [Связь аккаунт–заказ](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/relations/subjects-to-ecommerce-module-orders/backend/repository/database/src/lib/schema.ts#L10) · [Связь профиль–товар](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/social/relations/profiles-to-ecommerce-module-products/backend/repository/database/src/lib/schema.ts#L17).

Гостевая сессия создаёт аккаунт и токены без создания профиля. Для зарегистрированного пользователя сервис ищет или создаёт один личный профиль; профиль ассистента может одновременно иметь связь `assistant` с человеком и `default` со служебным аккаунтом агента. Поэтому у профиля не всегда один связанный аккаунт, а у старого заказа может не быть однозначного профиля. Очистка неактивных гостей сейчас сохраняет аккаунты, у которых есть связь с заказом или профилем. [Гость](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/backend/app/api/src/lib/service/singlepage/init.ts#L68) · [Личный профиль](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/backend/app/api/src/lib/service/singlepage/social-module/profile/ownership.ts#L185) · [Связи ассистента](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/backend/app/api/src/lib/service/singlepage/social-module/profile/collection.ts#L93) · [Связь с агентом](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/backend/app/api/src/lib/service/singlepage/social-module/profile/ai/bootstrap.ts#L244) · [Условия очистки](https://github.com/singlepagestartup/singlepagestartup/blob/ec863071e53b551f7430bb2fdc88fbfa640e11cf/libs/modules/rbac/models/subject/backend/app/api/src/lib/service/singlepage/index.ts#L604).
