RBAC Subject разрешает текущий пользовательский Profile через subjects-to-social-module-profiles. Меню пользователя находится в Profile `ai-chat-user-menu`. Project selector и контейнер проектов — Profile `ai-chat-project-select` и `ai-chat-workspace`. Доступ к проекту требует профиль пользователя, profiles-to-chats, Chat/Profile variants и ID маршрута; чужой или отсутствующий профиль показывает unavailable. Header получает selector через slot.

Project Profile `ai-chat-project` собирает настройки, навигацию и Chat. Profile navigation выделена в `profile/ai-chat-navigation`. Chat `ai-chat-workspace` разрешает выбранный Thread через `chats-to-threads/ai-chat-find`. Brief, Strategy, Brand, Design, Products, добавленные продукты и рабочие разговоры — отдельные Threads одного Chat. Старый projectWorkChats удалён. `projectThreadGraph` проецирует существующий агрегат редактора в самостоятельные Chat, Thread, Message и relation records. Локальные IDs выбора документа/разговора хранятся отдельно от полей Thread.

Thread `ai-chat-workspace` владеет заголовком, conversation, proposal, Working On, composer и редактором Sources. `thread/ai-chat-conversation` отображает сообщения, разрешённые через `threads-to-messages/ai-chat-find`, по orderIndex. `message/ai-chat-message` отображает одну запись с исторической атрибуцией и вложениями. Старый `message/ai-chat-conversation` удалён; website re-export и тесты обновлены. Создание и настройки Thread имеют варианты `ai-chat-create` и `ai-chat-settings`. Рабочие Threads используют весь набор Sources Profile, без Working On и выбора документов при создании/настройке.

Источники остаются у Profile. Profile-to-Source find ограничивает и навигацию, и редактор. `projectKnowledge` формирует Source.slug; bundle хранит sourceSlugs. Thread фильтрует связанную группу по slug; Working On выбирает Source IDs внутри неё. Каждый блок редактора — `knowledge.source/ai-chat-section`. Files разрешаются через sources-to-file-storage-module-files по sourceId и orderIndex; пары уникальны, detach сохраняет File и другие связи. Bundle membership, References/Generated, review и delivery — параметры визуального адаптера. Source не содержит documentId или вложенный массив Files. Правки пользовательского блока content сохраняют описания материалов; Chunks остаются производными записями поиска.

Поля Thread и orderIndex отношений сверены с production fields/singlepage.ts. Source, Profile-to-Source и Source-to-File контракты также сверены с production schema/README/frontend. Импорты production не добавлены. Агрегат редактора, локальные сообщения-ответы и snapshots reviewed документов остаются в адаптерах; независимая persistence, API, tool routing, ограничения ролей и векторный индекс — последующая работа.
