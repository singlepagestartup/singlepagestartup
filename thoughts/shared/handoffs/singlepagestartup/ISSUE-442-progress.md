## Incident Log

<!-- incident-count: 3 -->

### Incident 1 — повторный импорт метаданных страниц

- **Occurrences**: 1
- **Stage**: данные Host Page
- **Symptom**: при повторном seed появлялись лишние связи SEO.
- **Root Cause**: отдельные записи Metadata для двух страниц требовали дополнительных связей с нестабильной идентичностью при импорте.
- **Fix**: страницы ссылаются на собственные локализованные поля SEO через маски. Повторный seed тех же 16 снимков в отдельной PostgreSQL сохранил записи и связи.
- **Reusable Pattern**: проверять второй импорт и перечитывать результат через Host findByUrl и SEO на обоих языках.

### Incident 2 — поиск учитывал только видимую страницу чатов

- **Occurrences**: 1
- **Stage**: проверка Social Chat
- **Symptom**: чат на более поздней странице отсутствовал в поиске.
- **Root Cause**: клиент фильтровал уже загруженную страницу. Поиск по сырому содержимому поля title также захватывал скрытые переводы и ключи JSON.
- **Fix**: сервер ищет по отображаемому названию в пределах членства и прав пользователя до выбора страницы. Тест охватывает 111 чатов, старые строковые заголовки и чат без названия.
- **Reusable Pattern**: проверять поиск совпадением за пределами первой страницы на языке интерфейса.

### Incident 3 — статус отменённого заказа

- **Occurrences**: 1
- **Stage**: проверка карточки заказа
- **Symptom**: покупатель мог видеть ожидание оплаты после отмены.
- **Root Cause**: карточка всегда отдавала предпочтение состоянию работы.
- **Fix**: карточка использует этап исполнения только у активного заказа. Отмену и ошибку оплаты показывает по состоянию самого заказа.
- **Reusable Pattern**: отдельно проверять терминальное состояние заказа при устаревшем этапе работы.

## Summary

Ветка `codex/issue-442-profile-orders-chats`. [PR #444](https://github.com/singlepagestartup/singlepagestartup/pull/444).

Покупатель запросил правку первого превью и принял вторую версию. На уточнение о заголовке и оплате ответил штатный обработчик агента через локальный тестовый транспорт модели. Платёж dummy на 25 ₽ завершился, покупатель скачал оригинал и PDF-чек. После повторного входа сохранились статус заказа и переписка. Обычный чат проверен отдельно между двумя участниками. Проверены мобильный профиль, чужой заказ, неверный UUID и старый заказ без обсуждения.

Прошли сборки Host и Studio Storybook, TypeScript Host и Studio, 60 целевых тестов RBAC, 18 тестов Host SEO, интеграционная проверка Ecommerce с PostgreSQL и повторный seed 16 записей на отдельной базе. Проверка зависимостей обработала 16 861 файл без нарушений. Линтер завершился с шестью существующими предупреждениями в Host. Проверка циклов Studio прошла. Отдельный тест имён импортов сообщает о четырёх существующих местах в CRM и Social.
