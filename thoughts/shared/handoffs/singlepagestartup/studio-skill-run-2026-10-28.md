# Прогон singlepagestartup: Code Framework → AI Chat

Дата: 2026-10-28. Ветка: `codex/studio-linear-workflow`. Область проверки — локальный Studio и его документы. Рынок по ответу оператора: русскоязычная аудитория, Россия.

## Как выполнен прогон

Прочитаны маршрут `.codex/skills/singlepagestartup/SKILL.md`, канонический workflow, роли и шаблоны выбранных разделов. Контекст взят из существующих Brief, Product, подробных условий, Research, Sales, Analytics, Strategy, Brand, Design и материалов продуктов. Команда сохраняла выбранный раздел и прогресс; содержательную работу по инструкциям выполнил агент. Сама CLI-команда не вызывает модель и не генерирует документы. Вызовы веб-чата через OpenRouter, запись в production Knowledge и проверка RAG в этот прогон Studio не входили.

## Найденные и исправленные ошибки

- Web Designer всё ещё запрещал старт без подтверждённых Strategy и Brand. Условие удалено; обновлены соответствующие инструкции AI Chat и их контрольные суммы.
- В паспорте Code Framework несколько разделов содержали только ссылки. Условия возвращены в краткий самостоятельный текст.
- Русские заголовки Markdown превращались в повторяющиеся `#-`. Рендерер сохраняет кириллицу; тест проверяет ссылки и совместимость английских якорей.
- Шаблон Research ссылался на отсутствующий `agent-guide`; теперь указан действующий справочник.
- У двух изображений маскота были неверные пути и отсутствовали `proposal_id`/`lifecycle`. Записи исправлены; статус остался `proposed`.
- Проверка контрактов вариантов не распознавала строковый литерал с `as const`. Исправлено чтение AST; проверка регистрации варианта сохранена.

Во встроенном браузере сохранение файла не подтверждено.

## Что остаётся по данным

Частотность, региональная выдача, позиции и предпочтение клиентов не измерены. Предварительные группы не считаются подтверждённым ядром; статьи имеют `seo.status: exploratory-draft`. В Semantics есть задания на Wordstat и топ-10 Яндекса с полями выгрузок. Прямой осмотр NimbleFlow не удался; записан только поисковый фрагмент и ограничение.

Следующий содержательный шаг — загрузить эти измерения и уточнить группы/страницы. Продолжить можно командой `npm run singlepagestartup -- --section semantics --product singlepagestartup` или с `--product ai-chat`. Новый замер не требует пересоздавать Brief, Brand и Design.
