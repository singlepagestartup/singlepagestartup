# Бриф проекта SinglePageStartup

## Проект и продукты

SinglePageStartup — проект и бренд с двумя связанными продуктами. AI Chat (`ai-chat`) — размещённый сервис для подготовки и редактирования письменных документов проекта: Brief.md, Strategy.md, Brand.md, Design.md и Products.md. Code Framework (`singlepagestartup`) — существующая программная основа для создания собственных продуктов, распространяемая через GitHub под лицензией MIT. Продажа заказных сайтов не входит в текущее предложение.

## Клиенты и ценность

AI Chat предназначен прежде всего для человека, который самостоятельно начинает предпринимательский проект и хочет упорядочить разрозненные заметки, материалы и решения. Пользователь обсуждает документы с ассистентом, проверяет и редактирует предложенные факты, сохраняет знания и может экспортировать результат. Code Framework адресован начинающим разработчикам, работающим с Claude Code или Codex Desktop: готовые общие функции помогают сосредоточиться на логике своего продукта.

## Текущее состояние и ресурсы

Кодовая база разрабатывалась командой несколько лет; в ней есть регистрация, разграничение доступа, ecommerce и платежные интеграции. Владелец принимает продуктовые решения и финансирует развитие своими средствами и временем. Поддержка бесплатного кода оказывается по возможности; обязательства непрерывной поддержки не заявлены.

## Цели и границы

Первый этап AI Chat — качественное описание проекта и его продуктов. Создание готовых лендингов и публикация на сервере относятся к последующим этапам. Цели: проверить полезность процесса подготовки документов, развивать повторное использование фреймворка и привлекать вклад сообщества. Численные цели, цены, бюджет и сроки в этой короткой версии не заданы.

## Визуальные исходные требования

Выбрано направление Living Focus. Шрифт Onest используется для заголовков, текста и интерфейса; нужны латиница и кириллица. Палитра: графит, холодный серый, белый и лаймовый акцент #BFEF61. Тёплые жёлтые и кремовые фоны исключены.
