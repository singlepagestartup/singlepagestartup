# Документы продуктов

Пользовательский порядок работы описан в [инструкции Workspace](../README.md). Контракт для агента — `.agents/references/studio-artifacts.md`, подготовка материалов — `.agents/references/materials.md`.

В `singlepage/catalog.yaml` находятся продукты фреймворка, в `startup/catalog.yaml` — продукты клиента. Каждый продукт хранится в собственной папке с постоянным ID. Его видимое название задаётся каталогом.

## Состав продукта

| Источник         | Содержание                                                     |
| ---------------- | -------------------------------------------------------------- |
| `product.md`     | Состав, назначение, применение, стоимость и развитие           |
| `audience.md`    | Ситуации клиентов, потребности, критерии и возражения          |
| `competitors.md` | Сравнение предложений, ограничения, выводы и первоисточники    |
| `semantics.md`   | Измерения спроса, выдача, группы запросов и страницы           |
| `economics.md`   | Доходы, действия, ресурсы, партнёры и затраты                  |
| `sales.yaml`     | Сегменты, привлечение, карта пути клиента и следующие действия |

Каждый документ доступен отдельной историей Storybook. Результаты исследования и таблицы находятся на соответствующих страницах. Внутренние ссылки ведут на истории или их разделы; внешние — на первоисточники.

## Материалы

Сайт, презентация и реклама содержат короткий контекст по шаблону и готовый макет. Текст и оформление редактируются в React/HTML-компоненте самого материала. У каждой статьи своя история с текстом, SEO, видео, обложками и постами.

Контекст каждого материала указывает `journey.segment` и `journey.stage` из продаж своего продукта. Содержание использует описание, аудиторию, конкурентов, семантику, экономику, CJM, стратегию, бренд и дизайн.

Общие просмотр, навигация и экспорт находятся в `workspace/utils/`. Ресурсы принадлежат `workspace/assets/<layer>/`. Выгрузки сохраняются через браузер или в `apps/studio/output/`.
