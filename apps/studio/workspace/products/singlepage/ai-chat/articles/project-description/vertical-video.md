# Вертикальное видео

Сценарий 9:16, 30 секунд. Тот же владелец услуги и один вопрос: как сохранить условия прайса в описании. Видео не снято.

| Интервал  | Кадр                                           | Реплика                                                                                                               |
| --------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:06 | «По 3 снимка каждого товара»                   | «В прайсе — три снимка каждого товара. В сокращённом описании слово “каждого” легко потерять».                        |
| 0:06–0:14 | Таблица: объём, цена, срок                     | «Перед текстом соберите условия в таблицу: до десяти товаров, пятнадцать тысяч рублей, три рабочих дня после съёмки». |
| 0:14–0:23 | Первый абзац из статьи; выделены те же условия | «Поручите ИИ написать описание по таблице. Потом сверьте числа и условия: состав услуги должен остаться прежним».     |
| 0:23–0:30 | Статья с образцом                              | «В статье — учебный пример фотографа, шаблон и запрос к ИИ для вашей услуги».                                         |

Обложка: «Не потеряйте условия услуги». Графика — две версии фразы с выделенным словом «каждого».
