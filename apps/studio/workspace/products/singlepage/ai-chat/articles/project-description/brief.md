# Как написать описание услуги для сайта: пример и шаблон

## Для кого и зачем

**Читатель:** Владелец услуги, которому нужен текст предложения для своего сайта.

**Вопрос:** Как превратить условия одной услуги в понятное описание для сайта?

**Результат чтения:** Заполненный пример услуги фотографа, шаблон и запрос к ИИ со сверкой условий.

## Связь с продуктом

Знакомство с AI Chat; статья → страница сервиса → вход → материалы своей услуги. Разработка сайта не требуется для получения текста. Этап пути клиента: `business-users / discover`. [Продажи и путь клиента](/?path=/story/workspace-10-products-singlepage-ai-chat--sales).

Следующее действие: [Перейти на страницу AI Chat и подготовить описание своей услуги](/?path=/story/workspace-50-materials-singlepage-ai-chat-website--website). В AI Chat можно загрузить прайс и заметки, чтобы подготовить описание по условиям своей услуги.

## Основание темы

Поисковая тема: «описание услуги для сайта» — 116 запросов без операторов. В выдаче преобладают инструкции по тексту и структуре страницы услуги. Бизнес-планы, генерация идей и карточки маркетплейсов отделены.

Запрос «описание услуги для сайта» разобран в [семантике продукта](/?path=/story/workspace-10-products-singlepage-ai-chat--semantics). Частотность, разбор страниц из поиска и разделение тем приведены в SEO-задании ниже.
