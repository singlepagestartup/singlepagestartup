# Горизонтальное видео

Название: «Описание услуги для сайта из прайса и заметок». Формат 16:9, сценарий на 3 минуты. Для владельца услуги, которому нужен её текст на сайте. Пример съёмки учебный; видеозапись не выполнена.

| Интервал  | Что показываем                                        | Реплика                                                                                                                                                                               |
| --------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:30 | Фраза «индивидуальный подход» и рядом таблица условий | «Фотографу нужно описание съёмки товаров. В прайсе уже есть то, что хочет знать клиент: количество, результат, цена и срок».                                                          |
| 0:30–1:15 | 10 товаров, 3 снимка каждого, 15 000 ₽, 3 рабочих дня | «Сохраняем единицы и условия. Три снимка каждого товара. Три рабочих дня после съёмки. Эти слова определяют, что получает заказчик».                                                  |
| 1:15–2:00 | Полный первый абзац из статьи, затем порядок работы   | «Из таблицы получается описание для страницы. Следом объясняем передачу товаров и действие: прислать список для обсуждения съёмки».                                                   |
| 2:00–2:40 | Запрос к ИИ и сверка по таблице                       | «Поручаем ассистенту использовать только условия услуги. После текста сверяем цену, количество и начало срока. Противоречие в исходниках должно остаться вопросом, а не новой ценой». |
| 2:40–3:00 | Статья с шаблоном, затем AI Chat                      | «В статье есть шаблон и запрос. В AI Chat можно сохранить сведения своей услуги и использовать их при следующих правках».                                                             |

Обложка: «Из прайса — в описание услуги». На ней фрагмент таблицы и готовый первый абзац; без фотографии, не связанной с разбором.
