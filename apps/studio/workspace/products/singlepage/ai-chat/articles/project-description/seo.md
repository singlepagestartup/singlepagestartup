# SEO

## Решение по статье

Поисковая инструкция для владельца услуги, который пишет её описание для своего сайта. Результат — готовый текст по условиям, а не бизнес-план, общий бриф или подборка форматов. Существующая статья переориентирована на этот вопрос и отнесена к AC-G05.

## Спрос и намерение

Рынок: русский язык, Россия. Wordstat: регион 225, все устройства. Замеры указаны с периодами; широкие значения включают дополнительные слова и не равны числу покупателей.

В [первой десятке органических результатов](/?path=/story/workspace-10-products-singlepage-ai-chat--semantics#описание-услуги-для-сайта) преобладают инструкции по описанию и оформлению услуги. Формат статьи соответствует вопросу. Запрос «описать бизнес идею» не используется как основная фраза: там другое содержание и учебная примесь. 116 — широкое число обращений, не прогноз трафика.

Порядок ответа: Условия услуги → первый абзац → порядок и CTA → шаблон → запрос и сверка → AI Chat.

Адрес предназначен для будущего переноса в Host. Canonical задаётся по фактическому публичному URL; Storybook не используется как адрес публикации.

## Пересечения и ссылки

AC-G01 (описать идею), AC-G02 (бриф на разработку), карточки товаров и генерация бизнес-идей не назначены этой странице. Со статьёй Code Framework о сайте пересекается подготовка условий; здесь результат — текст, там — страница с работающей заявкой. Дополнительную статью «как написать продающее описание услуги» с тем же результатом создавать не нужно.

Основной переход в тексте — [страница продукта](/?path=/story/workspace-50-materials-singlepage-ai-chat-website--website); он продолжает путь из [продаж](/?path=/story/workspace-10-products-singlepage-ai-chat--sales). Пост и видео ведут к этой статье. Вывод о разделении тем сделан по вопросу и результату; автоматическая кластеризация по совпадению URL не проводилась.
