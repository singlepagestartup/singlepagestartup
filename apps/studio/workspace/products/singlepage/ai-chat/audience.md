# Аудитория

## Сегменты и ситуации

Аудитория AI Chat — люди, которые используют знания о своём бизнесе для подготовки контента, рекламы, решений и технических заданий. Их объединяет сегмент `business-users`: владелец, эксперт, маркетолог или участник нового проекта знает продукт и регулярно должен объяснять его другим.

| Ситуация                                           | Для чего нужен AI Chat                                                                                                                              |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Владелец или эксперт продвигает действующую услугу | Превратить описание услуги, опыт, записи выступлений и вопросы клиентов в статьи, публикации и тексты с точными условиями.                          |
| Маркетолог готовит рекламную кампанию              | Связать сообщение и креатив с аудиторией, продуктом, возражением и следующим действием; использовать одну версию цен и обещаний во всех материалах. |
| Предприниматель готовит запуск                     | Собрать сведения, сравнить альтернативы, сформулировать предложение и подготовить материалы первого знакомства с продуктом.                         |
| Владелец описывает будущий сайт или сервис         | Перевести задачу бизнеса в техническое задание с действиями пользователей, функциями и критериями готовности.                                       |

Пользователь может сам оплачивать сервис либо работать от имени организации с уполномоченным плательщиком. Контент и реклама дают самостоятельный результат. Переход к разработке сайта выбирается для отдельной задачи.

## Потребности и ожидаемый результат

Для регулярных материалов важны повторное использование знаний и точность условий. Ассистенту нужны состав продукта, цена, ограничения, позиция бренда и сведения об аудитории. Статья должна объяснять задачу читателя, объявление — конкретное предложение, а техническое задание — требуемое поведение будущего продукта.

Такая работа уже выделена в категории ИИ-ассистентов. [ChatGPT Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt) объединяет файлы, инструкции и разговоры для повторяющихся задач, в том числе подготовки контента. [Алиса AI для бизнеса](https://alice.yandex.ru/support/ru/assistant/alice-business/knowledge-bases) использует базу знаний для вопросов по источникам, анализа рынка и текстов с учётом редакционных правил. Значит, сам факт загрузки файлов не выделяет AI Chat.

Рабочее отличие предложения SPS — сведения организованы вокруг бизнеса и отдельных продуктов, а результаты связаны с их задачами: статья объясняет услугу, реклама ведёт к подходящему действию, техническое задание определяет функции. Наиболее подходящая аудитория знает свой предмет, но тратит время на сбор исходных условий для каждого нового материала. Это вывод из сравнения способов работы, применённый к устройству AI Chat.

В следующей задаче используется выбранная база знаний.                                                                                                            |
| «Мне нужны статьи и реклама, а сайт уже есть»          | Подготовка контента — самостоятельный сценарий. Тексты, идеи креативов и сценарии можно использовать на существующем сайте, в рекламе и соцсетях.                                                                                                                                                 |
| «Я не хочу заполнять длинные анкеты»                   | Начало — имеющиеся файлы и задача. Агент извлекает сведения, исследует доступные источники и уточняет условия, которые известны только бизнесу.                                                                                                                                                   |

| «Один и тот же материал не подойдёт разным аудиториям» | Для задачи выбираются продукт, аудитория и цель. ## Выводы для коммуникации

Для владельца и эксперта главное сообщение — **«Соберите знания о своём бизнесе и создавайте на их основе статьи, рекламу и другие материалы»**. Пример первого результата: описание услуги и ответы клиентов превращаются в статью с предложением этой услуги. В следующем материале используются те же условия.

Для маркетолога важен переход от общей базы к разным сообщениям: один продукт, две аудитории, соответствующие им аргументы и креативы. Качество демонстрации определяется сохранностью фактов и пригодностью материалов для выбранного размещения.

Для предпринимателя, которому нужна разработка, сообщение другое: **«Подготовьте понятное техническое задание на свой цифровой продукт»**. Пример связывает действие клиента с функцией и ожидаемым результатом. Дальнейшая разработка и размещение становятся продолжением этой задачи.

Первое действие во всех случаях — попробовать AI Chat со своими материалами и одной задачей. В демонстрации человек видит результат по своему бизнесу: статью, рекламное сообщение или задание. Повод возвращаться — следующая содержательная задача и возможность использовать уже собранные знания.
