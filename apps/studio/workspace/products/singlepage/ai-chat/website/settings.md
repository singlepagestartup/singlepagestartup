# Settings

Manage the account and the selected project without mixing service settings into the business documents.

## Account

- Email and password
- Current token balance
- Purchase and receipt history

## Project

- Project name
- Active products
- Export the current business document
- Saved landing-page sandbox data
- Connected GitHub repository and authorization state
- Connected server, deployment status and public address
