# Подключения магазина и бюджет задачи

Материал описывает рабочее место владельца магазина для #418. В учебном магазине «Север» личный ассистент отвечает покупателю. Отдельные агенты исполняют поручения через OpenRouter и прямой OpenAI API. Владелец видит их имена, кошельки и внешние аккаунты.

## Настройка подключения

Владелец выбирает агента, провайдера, разрешённую модель и подключение по метке. Форма создания или замены ключа принимает секрет в закрытом поле. После сохранения карточка показывает метку, внешний аккаунт, версию и статус. Отзыв прекращает новые вызовы. Для недоступного по правам магазина экран показывает отказ без реквизитов подключений.

## Лимит и исполнение

У выбранной задачи показаны плательщик, лимит, резерв, подтверждённый расход и остаток. Владелец может явным действием изменить лимит. Перед началом попытки интерфейс показывает верхнюю сумму. При отсутствии покрытия задача ждёт бюджет. При отказе провайдера экран показывает состояние подключения и итог попытки. Если запрос ушёл, а результат неизвестен, резерв сохраняется до сверки.

## Сверка и квитанция

В записи попытки указаны технический агент, подключение, внешний аккаунт, модель и цель вызова. Для OpenRouter доступны ID генерации и стоимость аккаунта. При прямом OpenAI доступны ID ответа, входные и выходные токены и статус расчётной цены. Внутренние токены SPS, единицы модели и USD показаны раздельно. Квитанция показывает плательщика и получателя каждого внутреннего перевода. Внешняя стоимость приведена рядом с её аккаунтом.

## Значки

Phosphor через Studio Icon. `link` обозначает подключение, `key` — управление ключом, `wallet` — кошелёк, `arrow-right` — сверку, `warning` — состояние, требующее действия. Значок сопровождает статус или действие с текстовой подписью.
