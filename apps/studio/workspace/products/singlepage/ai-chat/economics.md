# Экономика

## Источники выручки

| Элемент              | Условия                                                                                                                                                                                                                                                   |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Плательщик и единица | Пользователь чата покупает токены. Один внутренний токен равен USD 0.001 расходов провайдера.                                                                                                                                                             |
| Цена                 | Продажа с наценкой 30% к этим расходам по фиксированному курсу 100 рублей за доллар: 0.13 рубля за токен.                                                                                                                                                 |
| Пакеты               | Пополнения на 100, 300, 500, 1 000 и 3 000 рублей по одной цене токена. Больший пакет не даёт скидки.                                                                                                                                                     |
| Момент списания      | Один токен списывается при отправке данных модели; окончательный расчёт происходит после ответа, когда известна стоимость. Успешный запрос стоит не менее одного токена, или 0.13 рубля. Итоговое списание за неудачный или отменённый запрос равно нулю. |
| Условия              | Токены не сгорают. Покупка обычно окончательна; денежный возврат решается отдельно и не заявлен как обязательное право. При регистрации выдаётся текущий бесплатный лимит.                                                                                |
| Приём оплаты         | Платежи в России принимаются через онлайн-кассу. Получатель и реквизиты настраиваются в интерфейсе продукта.                                                                                                                                              |

Наценка берётся при пополнении, а не повторно при расходовании: использование учитывается по себестоимости. Стоимость каждого успешного ответа округляется вверх до целого токена. Из-за округления может оставаться разница между оплатой и расходами провайдера, особенно на дешёвых моделях. Фиксированный курс 100 рублей сохраняет наценку лишь пока рыночный курс не выше него.

Баланс может уходить в минус. Порог долга — USD 2 расходов провайдера: USD 2 ÷ USD 0.001 за внутренний токен = 2 000 внутренних токенов. При балансе −2 000 токенов или ниже новые платные запросы блокируются до пополнения выше этого порога. Порог ограничивает отправку новых запросов. Уже отправленный запрос завершается и рассчитывается после ответа; его стоимость не ограничена этим порогом. Сохранённая работа остаётся доступной.

При неудачном или отменённом ИИ-запросе возвращаются все списанные за него токены, включая начальный токен и окончательный расчёт. Клиент не оплачивает запрос, даже если провайдер понёс расходы; они остаются затратами сервиса. Полный возврат токенов отличается от индивидуального решения о возврате денег за пакет.

AI Chat оплачивает запросы к моделям через API. Для экономики сервиса важны объём используемого контекста, число запросов и правок на один результат — статью, рекламный материал, описание или ТЗ. Повторное использование знаний сохраняет факты проекта в работе. Для пути разработки дополнительно важен состав готовых модулей SPS: подключение существующих функций должно уменьшать расходы на их повторную генерацию.

Будущая публикация из чата ведёт к партнёрскому размещению проектов на серверах. Доля платежей привлечённых клиентов учитывается в экономике Code Framework. Расход ИИ остаётся в AI Chat; одна партнёрская выплата не дублируется в выручке обоих продуктов.

## Основные действия

Развивать и поддерживать веб-чат: принимать файлы клиента, поддерживать знания о бизнесе, находить в них сведения для следующих ответов и готовить статьи, рекламу, описания, презентации и технические задания. Владелец оценивает первые пользовательские сессии и исправляет недостатки работы со знаниями и материалами. Начальный уровень поддержки — обработка обращений в течение 24 часов, без постоянного присутствия оператора и срока решения. Клиентский процесс описан в [продажах](/?path=/story/workspace-10-products-singlepage-ai-chat--sales#карта-пути-клиента-cjm).

## Основные ресурсы

| ID ресурса        | Состав и доля                                                                                                                                                      | Доступность                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| `founder-time`    | Половина времени разработки и поддержки владельца; 80% его остальных действий. Вторая половина разработки и поддержки и оставшиеся 20% относятся к Code Framework. | Разработка, поддержка и продвижение сервиса.                            |
| `repository`      | Общая основа, распространяемая Code Framework и используемая сервисом. Учтена у Code Framework.                                                                    | 15 модулей, 61 модель, 98 связей в текущем репозитории.                 |
| `service-host`    | Сервер Contabo в Амстердаме. PostgreSQL/pgvector хранит материалы и их числовые представления для поиска по смыслу.                                                | Полностью относится к этому продукту; Code Framework его не использует. |
| `provider-budget` | Оплачиваемые владельцем расходы ИИ, хранения и платежей.                                                                                                           | Финансирование API, хранения и приёма оплаты.                           |

## Основные партнёры

| Поставщик      | Функция и зависимость                                                                                                                                                               |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenRouter     | Все запросы к моделям и вся векторизация. Доступны модели, заявленные маршрутизатором; загрузки векторизует `qwen/qwen3-embedding-8b`. Изменение цен напрямую меняет себестоимость. |
| Contabo        | Сервер в Амстердаме с сервисом и корпусом. Резервные копии сохраняются до шести месяцев после удаления аккаунта; проект не может сократить срок.                                    |
| Онлайн-касса   | Приём платежей в России.                                                                                                                                                            |
| GitHub         | Зависимость будущей публикации: разрешение для одного репозитория клиента и процесс развёртывания в Actions.                                                                        |
| Beget, Timeweb | Планируемые варианты хостинга будущего предложения развёртывания. Их ограничения OpenRouter названы причиной размещения самого AI Chat на Contabo.                                  |

Для будущей публикации планируются партнёрства с хостинг-провайдерами и доля платежей привлечённых клиентов. Публикация подключает домен клиента через API выбранного провайдера.

## Структура затрат

| Расход                       | Основание                                                                                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Разработка и поддержка       | Половина соответствующего времени владельца по `founder-time`. Учитывается время, не деньги.                                                            |
| Остальные действия владельца | 80% оставшегося времени, включая продвижение; 20% относятся к Code Framework. Учитывается время, не деньги.                                             |
| Использование ИИ             | Запросы OpenRouter зависят от использования. Успешные запросы оплачиваются по условиям токенов; расходы провайдера при неудаче или отмене несёт сервис. |
| Векторизация и хранение      | Обработка загруженных документов и хранение данных для поиска в pgvector. Расход зависит от загрузок, а не от оплаты; пользователю не выставляется.     |
| Хостинг                      | Сервер Contabo; расходы не меняются пропорционально использованию.                                                                                      |
| Приём платежей               | Комиссии онлайн-кассы.                                                                                                                                  |

Денежные расходы продвижения остаются у Code Framework. Время владельца распределяется по `founder-time` из основных ресурсов; это распределение не меняет принадлежность денежных расходов.

### Финансирование

Время и деньги владельца покрывают работу сервиса, пока её не покрывают поступления. Выручка AI Chat позволяет поддерживать бесплатный фреймворк. Экономика продуктов учитывается раздельно, чтобы один не скрывал расходы другого.
