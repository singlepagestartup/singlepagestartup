# Operations & Economics

## Model scope

`framework-service` combines **[Code Framework](../../singlepagestartup/product.md)** (`singlepagestartup`) and **[AI Chat](../../ai-chat/product.md)** (`ai-chat`) around a shared software foundation. Code Framework gives makers free reusable functions for their products. AI Chat will provide business-specific answers as a hosted service, with token purchases funding continued use.

A useful chat experience introduces interested makers to the foundation. They can obtain it through GitHub and build with a coding agent. Token purchase is optional for this path; chat consumers can remain consumers.

The project owner decides and funds development. The shared model counts common resources once while keeping the products' revenue and expenses distinct.

## Revenue Streams

| Product        | Payer and paid value                                         | Planned terms                                                                                      |
| -------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| Code Framework | No payer for code and documentation.                         | Price **0**; no framework checkout or license fee.                                                 |
| AI Chat        | Business users buy tokens to continue using the hosted chat. | Token sales are selected; price, currency, token unit and purchase conditions remain to be chosen. |

Coding-agent subscriptions and a maker's own infrastructure are separate purchases. They are outside the free code offer and are not framework revenue. No revenue, margin or paying-customer forecast is set.

## Delivery and resources

### Key Activities

Develop the common functions and guidance; help makers adapt them to their businesses; develop and operate the hosted chat. Demonstrations, tutorials, short videos, searchable explanations and community participation support discovery. Reuse useful examples across channels and improve guidance from recurring questions.

The complete intended journeys belong to [Code Framework Sales](../../singlepagestartup/sales.yaml) and [AI Chat Sales](../../ai-chat/sales.yaml).

### Key Resources

| Resource ID       | Owner and shared use                                             | Available basis                                                       |
| ----------------- | ---------------------------------------------------------------- | --------------------------------------------------------------------- |
| `founder-time`    | Project owner's product work, documentation, promotion and help. | Time allocated as the project develops; no recurring hours committed. |
| `repository`      | Shared code and documentation serving both products.             | Existing foundation developed by a team over several years.           |
| `identity-assets` | Shared brand, fonts and visual materials.                        | Current approved project identity and registered assets.              |
| `provider-budget` | Owner-funded hosted AI Chat expenses.                            | No ongoing cash allowance is set.                                     |

### Key Partnerships

GitHub is the distribution platform. AI Chat will use AI providers, hosting and knowledge-storage services. No partnership agreement or dedicated supplier terms are specified. Makers choose the agents and external services for their own projects.

## Cost Structure

| Expense                        | Scope and basis                                                                   |
| ------------------------------ | --------------------------------------------------------------------------------- |
| Development, guidance and help | Shared owner time; separate time contribution from cash expense.                  |
| Promotion                      | Demonstrations and reusable content; funded from available shared time and money. |
| Hosted chat                    | AI usage, knowledge storage, hosting and payment costs; attributable to AI Chat.  |
| Maker's product                | Agent and infrastructure expenses paid by the maker.                              |

Recurring totals are unset. Record shared costs once; allocate them between products only with an explicit basis. Assess AI Chat's token revenue against its attributable service costs.

### Funding

The owner's time and money fund framework development. No external financing is committed. AI Chat receipts are intended service revenue, separate from that funding.

## Assumptions and decision rules

- `bridge`: useful chat experience encourages interested makers to adopt the foundation.
- `framework-growth`: distinguish attention and stars from product use, repeat use and contributions.
- `service-viability`: useful answers and repeat token purchases must support the service's costs.
- `capacity`: scale promotion and help to available time and money; support has no guaranteed schedule.
- `channel-access`: use the selected organic channels and prioritize topics that attract relevant users.
- `proof`: [framework Research](../../singlepagestartup/research.md) and [AI Chat Research](../../ai-chat/research.md) examine these business assumptions. No numerical growth or savings claim is established.
