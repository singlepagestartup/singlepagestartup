# Конкуренты

## Границы сравнения

Code Framework помогает создать сайт или веб-приложение с готовыми бизнес-модулями и дорабатывать его с ИИ-агентом. Предприниматель выбирает между конструктором, генерацией приложения и собственным кодом; создатель приложения также сравнивает стартовые проекты. Здесь сопоставлены функции, стоимость входа, переносимость и обслуживание. Поисковые страницы и запросы приведены в [семантике](/?path=/story/workspace-10-products-singlepage-singlepagestartup--semantics#поисковая-выдача).

Основания — официальные страницы, документация и открытый код. Выводы о подходящих ситуациях следуют из различий предложений; это не результаты опроса клиентов SPS или испытания одинаковой задачи во всех продуктах.

### Имеющийся код и способ знакомства

[Агент программирования](https://code.claude.com/docs/en/overview) может создать проект с нуля или изменить уже существующий. Для небольшой задачи знакомый проект избавляет от переноса данных и изучения нового фреймворка. Ценность SPS возникает, когда его готовые модули действительно покрывают нужную работу; число модулей само по себе этого не обеспечивает.

Предпринимательская аудитория есть и у конкурентов: [Lovable для малого бизнеса](https://lovable.dev/small-business) предлагает сайты, запись на услуги и внутренние инструменты. В [кейсе Alpine Ventures](https://lovable.dev/blog/2025-01-23-how-a-venture-capitalist-rebuilt-his-website-and-internal-data-platform-with-lovable) описаны публичный сайт и внутренний инструмент одного владельца. Это конкретный пример применения, а не измерение спроса на SPS.

Пути знакомства различаются. Open SaaS даёт демо, документацию и курс до использования. ShipFast связывает функции, цены, FAQ и выбранные продавцом отзывы с покупкой. Makerkit показывает примеры B2B-интерфейса и инструменты агентам. Вариант SPS для предпринимателя — сначала попробовать работу со сведениями своего бизнеса в AI Chat; GitHub остаётся отдельным входом для человека, уже готового развернуть и дорабатывать код.

## Выводы

**Для обычного сайта конструктор требует меньше настройки.** У Тильды уже есть страницы, заявки и торговля. Code Framework нужен, когда проекту требуются собственные правила заказа, права пользователей, связи товаров и статей или интеграция с бизнес-системой.

**У стартовых проектов уже есть авторизация, платежи и инструкции агентам.** Содержательное предложение SPS — совместная работа каталога, заказов, контента, страниц и прав доступа. Open SaaS, Makerkit и NimbleFlow исключают позиционирование через одну лишь бесплатность, AI или русскоязычность.

**Экспорт кода доступен и в ИИ-конструкторах.** Преимущество SPS — управляемая владельцем структура проекта и готовая бизнес-логика, подходящая конкретной задаче. Облачные альтернативы выигрывают удобством среды и размещения; свой сервер включает эксплуатационные обязанности. В текущем SPS есть сценарии настройки Ubuntu/Ansible/Docker Swarm, а партнёрский запуск одной кнопкой относится к развитию предложения.

**Знакомство начинается с задачи бизнеса.** Проба в AI Chat помогает описать продукт, собрать знания и определить нужные функции. Следующий технический шаг — использовать модули Code Framework, если требуется свой сайт или сервис. Для разработчика прямой доступ к репозиторию сохраняется. Из этого сравнения не следует обещание меньших расходов или более быстрой разработки на любом проекте.
