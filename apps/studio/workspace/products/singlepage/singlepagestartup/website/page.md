# Build your product on a foundation you can reuse.

Code Framework · Free code

Start with registration, carts and payments already in the framework. Describe your business logic to a coding agent and shape your product.

[Run the project on your machine](https://github.com/singlepagestartup/singlepagestartup)

Open the GitHub project and ask your coding agent to set it up locally. No AI Chat purchase required.

<!-- section: foundation -->

## Common functions. Your own logic.

Keep your attention on your business.

Code Framework brings common functions together so your agent has a foundation to work with. Put your effort into what makes your product useful.

| Function                   | Value                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------- |
| Accounts and access        | Reuse registration and access controls as you shape your product.                           |
| Carts, orders and payments | Start from ecommerce functions and payment integrations. Add the rules your business needs. |
| Code and guidance together | Work with the frontend, backend, documentation and instructions for coding agents.          |

[Explore the repository documentation](https://github.com/singlepagestartup/singlepagestartup#readme)

<!-- section: journey -->

## Start with a working local product.

You direct. Your agent changes the project.

| Step                 | What you do                                                                    |
| -------------------- | ------------------------------------------------------------------------------ |
| Open the project     | Follow the GitHub link and open the project with Claude Code or Codex Desktop. |
| Run it locally       | Ask your agent to set it up and show you how to open the interface.            |
| Make it your product | Describe a business change, explore the result and keep improving it.          |

<!-- section: request -->

### An example request for your coding agent

> Help me run this SinglePageStartup project on my machine. Walk me through the setup and help me open the resulting interface.

<!-- section: change -->

### Describe the change that matters.

Example request

> My store has a minimum order of six units. Add that rule while keeping the existing account and cart flow. Show me how the ordering experience changes.

Explore the result and ask for refinements. Keep using the foundation for this product and the next one when it fits.

## Before you start

| Question                            | Answer                                                                                                                                       |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Do I need to write the code myself? | Describe what you want to Claude Code or Codex Desktop. Your agent changes the code; you make decisions and explore the resulting interface. |
| Can I build a product of my own?    | Yes. Use the foundation for your project and add your own business logic, content and design.                                                |
| Must I buy AI Chat tokens first?    | No. The framework is available independently. Tokens pay for continued use of the hosted chat.                                               |
| Can I get help?                     | Use GitHub to ask questions or suggest improvements. Help and maintenance are provided as time permits.                                      |
