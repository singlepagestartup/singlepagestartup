# Как собрать свой магазин с ИИ-агентом

Вы продаёте керамику через социальные сети и хотите собственный интернет-магазин. На разработку с нуля бюджета нет, а разбираться во всём коде не хочется.

В статье — порядок работы с SinglePageStartup: создать свою копию проекта на GitHub, открыть её в ИИ-агенте, запустить сайт на компьютере и добавить товары. Затем настроить онлайн-оплату и уведомления владельцу в Telegram.

Внутри — команды и задания агенту для магазина с каталогом, корзиной и оформлением заказа. Отдельная инструкция объясняет GitHub тем, кто впервые работает с репозиторием.
