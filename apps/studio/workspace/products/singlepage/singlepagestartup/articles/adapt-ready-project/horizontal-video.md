# Горизонтальное видео

Название: «Минимальный заказ: как поставить задачу ИИ-агенту». Формат 16:9, сценарий на 3 минуты. Читатель статьи и зритель — владелец действующего магазина с ограничением размера партии. Пример учебный; видео ещё не снято.

| Интервал  | Что показываем                                                | Реплика                                                                                                                                                                                                                                  |
| --------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:30 | Корзина: три кружки и три тарелки                             | «Мастерская принимает заказ от шести изделий. Здесь две позиции, но шесть штук. Поэтому оформление разрешено. В задании агенту нужно точно объяснить, что мы считаем».                                                                   |
| 0:30–1:00 | Пять изделий и сообщение об остатке                           | «При пяти изделиях покупатель видит, сколько добавить. Если убрать товар после открытия формы, условие пересчитывается. Выбранные товары остаются в корзине».                                                                            |
| 1:00–1:45 | Задание из статьи; выделяются количество, смешивание и сервер | «Агент использует существующую корзину и оформление. На сервере он проверяет тот же минимум перед сохранением заказа. Изменение кнопки — только часть доработки».                                                                        |
| 1:45–2:30 | Таблица пяти случаев из статьи                                | «Проверяем пять, шесть, смешанную корзину и удаление изделия. Отдельно агент отправляет запрос напрямую: сервер тоже должен отклонить недопустимый заказ».                                                                               |
| 2:30–3:00 | Статья и страница Code Framework                              | «В статье есть полное задание и таблица. Code Framework предоставляет каталог, корзину и заказы для собственного проекта. На странице продукта показаны его возможности. Затем в AI Chat можно подготовить задание для своего магазина». |
