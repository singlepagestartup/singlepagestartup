# GitHub для первого проекта: регистрация и копия SinglePageStartup

## Для кого и зачем

**Читатель:** Владелец мастерской, который хочет собрать магазин с ИИ-агентом и впервые встречает GitHub.

**Вопрос:** Как зарегистрироваться, создать свою копию SPS и открыть её на компьютере?

**Результат чтения:** Понятия GitHub, репозитория и локальной копии; шаги в браузере и GitHub Desktop. У читателя своя копия, а агент работает в папке этого проекта.

## Связь с продуктом

Материал поддерживает первый запуск SinglePageStartup. Этап пути клиента: `makers / reached-explanation`. После подготовки проекта читатель возвращается к [созданию магазина](/?path=/story/workspace-50-materials-singlepage-singlepagestartup-articles--articles-ai-online-store) и запускает его с агентом.

## Основание темы

Справочная статья для подготовки к основной инструкции. Запросы «как зарегистрироваться на GitHub» и «как скачать репозиторий с GitHub» описывают её содержание; отдельная частотность и поисковые позиции не измерены. В [семантике продукта](/?path=/story/workspace-10-products-singlepage-singlepagestartup--semantics) тема выделена как помощь при первом запуске, без приписывания ей спроса статьи о магазине.

## Источники и границы

Официальные инструкции проверены 01.11.2026: [аккаунт](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github), [проект из шаблона](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template), [локальная копия в GitHub Desktop](https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-and-forking-repositories-from-github-desktop). Репозиторий SPS доступен как публичный шаблон.

Здесь нет регистрации аккаунта за читателя, реального демо-репозитория или утверждения о снятом уроке. Подготовка платёжного сервиса, сервера и магазина относится к основной статье.

## Состав комплекта

SEO-задание, инструкция и состояние публикации. В статье о магазине стоит ссылка на этот материал. Видео пока не создаётся.
