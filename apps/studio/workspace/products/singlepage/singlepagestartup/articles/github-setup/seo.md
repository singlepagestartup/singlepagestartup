# SEO

## Решение по статье

Справочная инструкция для первого проекта: зарегистрироваться на GitHub, создать собственную копию SPS из шаблона и скачать её через GitHub Desktop. Она снимает конкретное препятствие перед запуском магазина с агентом.

## Спрос и намерение

| Запрос                           | Состояние                        |
| -------------------------------- | -------------------------------- |
| как зарегистрироваться на GitHub | Частотность отдельно не измерена |
| как скачать репозиторий с GitHub | Частотность отдельно не измерена |

Материал подготовлен как часть пути к созданию магазина. Результаты выдачи и измеренный спрос не заявляются.
