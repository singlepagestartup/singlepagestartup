# Экономика

## Источники выручки

Исходный код и документация бесплатны по лицензии MIT. Бесплатное распространение помогает увеличить число цифровых продуктов, которые используют SPS, и повторное применение его модулей.

Планируемый доход Code Framework — партнёрское вознаграждение от хостинг-провайдеров. Клиент разворачивает свой проект через интеграцию SPS и оплачивает серверные мощности провайдера. Провайдер перечисляет SinglePageStartup долю платежей привлечённого клиента — revenue share. Ставка, срок начислений и порядок выплат будут закрепляться в партнёрских соглашениях.

Целевой вход в этот сценарий — предложение о публикации в AI Chat после подготовки задания и разработки продукта. Клиент подключает свой GitHub и кабинет хостинг-провайдера. Интеграция создаёт условия для повторного дохода, пока привлечённый клиент пользуется сервером и его платежи учитываются партнёрской программой.

## Основные действия

Развивать код и модули, обновлять документацию для создателей цифровых продуктов и их ИИ-агентов. По возможности помогать адаптировать код под бизнес.

Продвижение включает демонстрации и инструкции, короткие видео, страницы под поисковые задачи и ответы в профильных сообществах. На Code Framework приходится 20% деятельности владельца за пределами разработки и поддержки, включая продвижение; на AI Chat — 80%. Путь пользователя описан в [продажах](/?path=/story/workspace-10-products-singlepage-singlepagestartup--sales#карта-пути-клиента-cjm).

## Основные ресурсы

| ID ресурса        | Состав и доля                                                                                                              | Доступность                                                   |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `founder-time`    | 50% времени разработки и поддержки, а также 20% остальной деятельности владельца. Дополняющие доли относятся к AI Chat.    | Разработка, поддержка и продвижение проекта.                  |
| `repository`      | Общие код и документация, которые команда разрабатывала несколько лет. Учитываются здесь; AI Chat использует ту же основу. | 15 модулей, 61 модель, 98 связей в текущем репозитории.       |
| `identity-assets` | Общие бренд, шрифты и визуальные материалы.                                                                                | Текущая согласованная айдентика и зарегистрированные ресурсы. |

## Основные партнёры

**Хостинг-провайдеры** — направление планируемых партнёрств: API для подключения кабинета и сервера, развёртывания проекта и учёта привлечённых клиентов. Интеграция должна связывать оплату серверных мощностей с партнёрскими начислениями SPS.

**GitHub** — размещение исходного кода и клиентских репозиториев, запуск публикаций через GitHub Actions. Доступ при публикации относится к репозиторию проекта клиента.

## Структура затрат

| Расход              | Основание                                                                                                                                                                                       |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Разработка и помощь | 50% времени разработки и поддержки владельца по распределению `founder-time`.                                                                                                                   |
| Продвижение         | 20% времени владельца за пределами разработки и поддержки, включая демонстрации, короткие видео, поисковые страницы и участие в сообществах. Денежные расходы продвижения также относятся сюда. |
| Распространение     | Отсутствуют. GitHub хранит код без платы со стороны проекта.                                                                                                                                    |

Время владельца распределяется по видам деятельности под одним ID ресурса в обоих продуктах: здесь 50% разработки и поддержки и 20% остальных действий, дополняющие доли — в AI Chat. Одни и те же часы учитываются один раз.

### Финансирование

Продукт финансируется временем и деньгами владельца; выручка AI Chat помогает поддерживать бесплатный фреймворк.
