# SinglePageStartup Code Framework

Build your product on a foundation you can reuse.

Code Framework combines common application functions, source code, documentation and instructions for coding agents. Start with the business you want to create, then shape the product with Claude Code or Codex Desktop.

[Get Code Framework](https://github.com/singlepagestartup/singlepagestartup) · [Build with a coding agent](build-with-an-agent.md)

## What you can build on

| Foundation          | Use it for                                                                           |
| ------------------- | ------------------------------------------------------------------------------------ |
| Accounts and access | Registration, customer accounts and access rules.                                    |
| Commerce            | Catalogs, carts, orders and your business's buying rules.                            |
| Payments            | Payment integrations and the providers you choose for your project.                  |
| Code and guidance   | A shared frontend/backend, module documentation and project instructions for agents. |

Your business logic, content and design make the product yours. Use the functions that fit your idea and adapt the experience around your customers.

## Begin with your business

Tell the agent who the product serves, the problem it solves, what the customer receives and how the business earns money.

> I want to create [product] for [customer]. They need [result]. Help me describe the business model and customer journey using this project's workflow. Once we agree on that direction, use the framework to build the product and add [my business rules].

You set the direction. The agent works with the code. Explore the resulting interface, clarify the behavior you want and keep developing the product.

[Read the maker guide](build-with-an-agent.md)

## A simple example

A store may need a minimum order of six units. Ask the agent to add that rule to the existing cart while retaining the common account and payment functions. The new rule belongs to that business; the underlying functions remain useful for other products.

## The relationship with AI Chat

AI Chat is the planned hosted service for business-specific questions. It also shows the idea of a useful product built on the foundation. People can continue using the chat as consumers or choose the framework for their own projects. A chat-token purchase is not required to obtain the framework.

## Cost and support

Code and documentation are free. Coding-agent services, infrastructure and other services for your project are separate expenses. The source's terms are available in [LICENSE](https://github.com/singlepagestartup/singlepagestartup/blob/main/LICENSE).

Help and maintenance are provided as time permits. Use [GitHub Issues](https://github.com/singlepagestartup/singlepagestartup/issues) for questions and suggestions.

## Keep building

Continue improving your product and choose SPS again when it fits your next idea. Sharing an example, improving documentation or contributing code is optional.
