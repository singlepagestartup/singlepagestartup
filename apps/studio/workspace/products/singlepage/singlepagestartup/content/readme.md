# SinglePageStartup Code Framework

Создайте продукт на основе, которую можно использовать повторно.

Code Framework объединяет общие функции приложения, исходный код, документацию и инструкции для агентов-разработчиков. Начните с бизнеса, который хотите создать, затем развивайте продукт с Claude Code или Codex Desktop.

[Получить Code Framework](https://github.com/singlepagestartup/singlepagestartup) · [Разработка с AI-агентом](build-with-an-agent.md)

## Что можно взять за основу

| Основа            | Применение                                                                     |
| ----------------- | ------------------------------------------------------------------------------ |
| Аккаунты и доступ | Регистрация, аккаунты клиентов и правила доступа.                              |
| Торговля          | Каталоги, корзины, заказы и правила покупки вашего бизнеса.                    |
| Платежи           | Платёжные интеграции и выбранные для проекта провайдеры.                       |
| Код и инструкции  | Общие клиентская и серверная части, документация модулей и инструкции агентам. |

Бизнес-логика, контент и дизайн делают продукт вашим. Используйте подходящие функции и адаптируйте взаимодействие под клиентов.

## Начните с бизнеса

Расскажите агенту, для кого продукт, какую проблему он решает, что получает клиент и как бизнес зарабатывает.

> Хочу создать [продукт] для [клиента]. Ему нужен [результат]. Помоги описать бизнес-модель и путь клиента по процессу этого проекта. После согласования направления используй фреймворк для создания продукта и добавь [мои бизнес-правила].

Вы задаёте направление, агент работает с кодом. Изучайте интерфейс, уточняйте нужное поведение и продолжайте развитие.

[Прочитать руководство для создателя](build-with-an-agent.md)

## Простой пример

Магазину может понадобиться минимальный заказ в шесть единиц. Попросите агента добавить правило в существующую корзину, сохранив общие функции аккаунта и платежей. Правило принадлежит этому бизнесу; общие функции подходят и другим продуктам.

## Связь с AI Chat

AI Chat — планируемый готовый сервис для вопросов о конкретном бизнесе. Он также показывает полезный продукт на этой основе. Люди могут продолжать пользоваться чатом или выбрать фреймворк для собственных проектов. Для получения фреймворка не нужно покупать токены чата.

## Стоимость и поддержка

Код и документация бесплатны. Агенты-разработчики, инфраструктура и другие сервисы проекта оплачиваются отдельно. Условия исходного кода — в [LICENSE](https://github.com/singlepagestartup/singlepagestartup/blob/main/LICENSE).

Помощь и обслуживание предоставляются по возможности. Для вопросов и предложений используйте [GitHub Issues](https://github.com/singlepagestartup/singlepagestartup/issues).

## Продолжайте разработку

Улучшайте продукт и выбирайте SPS снова, когда он подходит следующей идее. Делиться примерами, улучшать документацию и вносить код необязательно.
