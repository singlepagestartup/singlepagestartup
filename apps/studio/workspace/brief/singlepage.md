# Бриф

## Проект и продукты

SinglePageStartup помогает предпринимателям применять знания о своём бизнесе в контенте и цифровых продуктах. ИИ использует сведения о клиентах, предложении и условиях для статей, рекламы и технических заданий; готовые модули фреймворка служат основой разработки сайта или сервиса.

В проекте два продукта. **AI Chat** (`ai-chat`) — разрабатываемый платный веб-сервис с цифровой базой знаний бизнеса. Ассистент использует её для статей, рекламы, текстов и технических заданий. **Code Framework** (`singlepagestartup`) — открытый исходный код для создания сайтов, сервисов и других цифровых продуктов. В нём уже связаны страницы, каталог, статьи, формы заявок, пользователи, права доступа, заказы и платежи.

## Клиенты и ценность

AI Chat предназначен для владельцев бизнеса, экспертов и маркетологов. Они передают сведения о продуктах, цены, документы, изображения и другие материалы. Ассистент помогает поддерживать описание бизнеса и готовить статьи, рекламные сообщения, идеи креативов, презентации и тексты с учётом этих знаний. Для разработки сайта или сервиса он формирует техническое задание: аудиторию, пользовательские действия, функции, подходящие модули SPS и нужные доработки. Результаты можно редактировать, экспортировать и использовать в следующих задачах.

Code Framework предназначен для предпринимателей и создателей цифровых продуктов, которые работают с ИИ-агентами разработки. Например, для сайта услуги они используют страницы, статьи и форму заявки; для магазина подключают каталог, корзину, заказы и оплату. Агент дорабатывает функции конкретного бизнеса, используя существующие модули. За счёт повторного использования проект стремится сократить объём генерируемого кода и расход токенов на разработку. Основной путь знакомства — попробовать AI Chat со сведениями своего бизнеса и определить нужные функции. Для готового к разработке пользователя доступен прямой вход через GitHub.

Первый рынок продвижения — русскоязычные пользователи в России. Начальный формат — страницы продуктов и статьи о работе с контентом бизнеса и создании цифровых продуктов с помощью ИИ.

## Конкуренты

Альтернативы AI Chat — ИИ-чаты с проектами и файлами, корпоративные базы знаний и работа в обычных документах. В [сравнении AI Chat](/?path=/story/workspace-10-products-singlepage-ai-chat--competitors#сравнение-предложений) разобраны Алиса AI, ChatGPT Projects, Claude Projects и другие варианты. Альтернативы Code Framework — стартовые проекты с исходным кодом, облачные конструкторы и разработка с ИИ с нуля; они сопоставлены в [сравнении фреймворка](/?path=/story/workspace-10-products-singlepage-singlepagestartup--competitors#сравнение-предложений). Выбор определяется задачей: готовить материалы на знаниях бизнеса или создавать собственный сайт и приложение.

## Текущее состояние

Code Framework доступен на GitHub по лицензии MIT. В репозитории есть бизнес-модули, инструкции для ИИ-агентов и сценарии развёртывания приложения, API и баз данных с настройкой домена и HTTPS. Studio содержит документы о бизнесе, исследования, дизайн и макеты материалов.

AI Chat разрабатывается как рабочая среда для знаний бизнеса, материалов и подготовки цифрового продукта. Документы и чаты составляют основу повторной работы с содержанием. Следующее направление — разработка по техническому заданию и публикация из чата с подключением GitHub и кабинета хостинг-провайдера.

## Бизнес и ресурсы

Код Code Framework бесплатен. Пользователь AI Chat покупает токены для работы с ИИ; SinglePageStartup оплачивает запросы к моделям через API. Экономика сервиса зависит от выручки за токены и затрат ИИ на работу со знаниями, создание материалов и разработку продукта. Готовые модули позволяют направлять работу агента на нужные изменения вместо повторного создания общих функций.

Второй планируемый источник дохода — партнёрское размещение проектов. Пользователь разворачивает продукт на сервере подключённого провайдера, а SinglePageStartup получает долю его платежей за серверные мощности — revenue share. Для этого планируется интеграция с хостинг-провайдерами: подключение кабинета, выбор сервера и запуск проекта прямо из AI Chat. Процент и порядок выплат будут определяться партнёрскими соглашениями.

Разработку и работу сервиса финансирует владелец. Время разработки и поддержки распределяется поровну между продуктами. Из остального рабочего времени 80% приходится на AI Chat, 20% — на Code Framework.

## Цели и признаки успеха

Цели AI Chat — регулярная работа с базой знаний бизнеса для контента и рекламы, а также путь от идеи до запущенного цифрового продукта на SinglePageStartup с разумными затратами на ИИ. Техническое задание связывает бизнес-задачу с готовыми модулями и конкретными доработками.

Для статей и рекламных материалов результатом становится подготовленный контент. Для разработки цифрового продукта планируемый путь в AI Chat:

1. Человек описывает проект и передаёт исходные материалы.
2. Ассистент готовит понятное техническое задание; человек уточняет и принимает результат.
3. ИИ-агент подключает нужные модули SPS и разрабатывает недостающие функции.
4. Человек проверяет продукт и принимает предложение о публикации.
5. Подключает GitHub и кабинет хостинг-провайдера; сервис разворачивает проект.
6. Продолжает развивать продукт и пользоваться сервером.

Для контента важны пригодные к использованию материалы и возвращение к знаниям проекта. Для разработки успех оценивается по результатам этого пути: принятым заданиям, запущенным продуктам, повторным доработкам и оплате серверных мощностей у партнёров. Для экономики важны стоимость ИИ на один подготовленный и запущенный проект, выручка от токенов и партнёрские выплаты. Для Code Framework — число использующих его проектов и повторное применение модулей.
